## Version 3.1.1 corrective release: comic rollback

The visual comic recap experiment introduced in version 3.1.0 was removed after review identified overlapping speech bubbles and obscured text in several generated images. The rollback removes the ten comic sections, image assets, transcripts, renderer, styles, and search hooks. It does not alter Phase 1, Phase 2, or Phase 3 instructional functionality.
