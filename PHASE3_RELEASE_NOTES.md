# Phase 3 Release Notes

**Version:** 3.0.0-phase3  
**Release date:** July 25, 2026

## Integrated judgment

The new Integrated Events area contains three reusable, data-driven events: a summer storm and IROL response, a winter capacity emergency, and a blackstart restoration island. Choices change system security, situational awareness, and coordination. Some decisions create recovery branches before the learner can continue. Completed events provide a debrief and direct links to the relevant lessons.

## Personalized practice

Every official blueprint subtopic now maps to a named misconception or decision pattern and lesson links. Adaptive practice ranks questions using the learner’s latest result, topic accuracy, credential weight, whether the item is unattempted, and cognitive complexity. The ranking is transparent and browser-local.

## Credential plans

The study-plan page now creates 8-, 12-, or 26-week plans for the selected TO, RC, BT, or BI blueprint. Time is allocated proportionally by scored-domain weight, while low-accuracy topics are placed earlier.

## Test-day mode

The existing exact-blueprint mock remains available. Test-day mode adds 20 unique experimental-style questions from outside the scored draw. During the run, those items are not identified. After submission, the credential cut comparison uses scored items only; experimental-style performance appears in a separate learning-only panel.

## Progress portability and privacy

Learners can export and import a versioned JSON bundle containing progress, credential, event state, exam state, review flags, and preferences. Optional activity analytics are off by default, stay in localStorage, are capped at 500 events, and can be cleared independently.

## Accessibility and usability

Phase 3 adds a skip link, main-content focus management, `aria-current`, live feedback announcements, complete form labels, high-contrast mode, 100/115/130 percent text settings, reduced-motion override, exam keyboard shortcuts, and responsive controls. Automated keyboard, text-scaling, mobile reflow, and accessible-name checks are included in the Phase 3 browser suite.
