# v3.2 Pre-SME Remediation Report

**Product:** NERC System Operator Study Console  
**Release:** 3.2.0-remediated  
**Baseline:** 3.1.1-no-comics  
**Date:** July 26, 2026

## Executive result

The independent punch list was substantively valid. Its highest-risk finding was the answer-length cue: 204 of 216 correct choices were originally the longest option. The second major issue was incomplete distractor feedback, including all 32 Phase 2 questions with none. Both defects have been remediated and are now enforced by release gates.

This release implements all structural corrections that can be made safely without an SME ruling. Items that require technical adjudication, external-content approval, or formal assistive-technology testing are isolated in `SME_REVIEW_PACKET.md` and the deferred section below.

## Punch-list disposition

### P0: Completed

- **P0-1 Answer-length cue:** All choices received a parallel contextual-normalization pass without deleting the qualifying clauses in correct answers. Correct keys now occupy each relative length rank equally often.
- **P0-2 Length-cue validation:** `scripts/validate.js` now fails above a 35% longest-key rate, above a +15-character per-item advantage, or when relative key-length ranks become materially imbalanced.
- **P0-3 Distractor feedback:** Every incorrect choice now has feedback. The Phase 2 batch is no longer blank, and the gate requires at least 90% coverage with zero items at 0/3.

### P1: Completed

- **SVG descriptions:** Visible SVGs receive a meaningful accessible label at runtime. The enhancement also traverses same-origin `srcdoc` activity frames. Browser QA checks all 57 lesson routes.
- **Route titles:** Each route updates `document.title` using the visible page heading and selected credential.
- **Timer warnings:** Five-minute and one-minute warnings are sent to the live region. The one-minute visual color change remains as a supplemental cue.
- **Subtopic floor:** Sixteen application/analysis questions raise all 31 blueprint subtopics to at least six authored items.
- **Video contrast:** External-video metadata now uses readable text color and size.
- **Glossary usability:** Added filtering across terms, acronyms, and definitions; A–Z navigation; letter headings; result count; mobile target sizing; and direct term links from search.
- **Standards resolution:** All 34 distinct question tags resolve to `data.standards.js`. `standards-question-coverage.csv` reports the 27 reference standards that currently carry zero questions.

### P2: Implemented where structural; SME review retained where technical

- **Content depth:** Expanded ten sections identified as especially thin. Median source prose rose to about 189 words. Broader depth expansion should follow SME comments rather than arbitrary word targets.
- **Priority visuals:** Added equipment primer, reactive-source comparison, voltage-profile lab, relay-coordination visual, and GIC path visual. Confirmed existing or newly wired visuals for protection SOE, cold-load pickup, three-part communication, and ACE.
- **Cognitive mix:** Added 16 application/analysis items without increasing recall count.
- **Absolute wording and negative stems:** Not automatically rewritten. All 26 identified items are isolated in `SME_REVIEW_PACKET.md` with original wording, key, standard tag, explanation, and ruling fields.
- **Sitting criterion:** Added an explicit study-console heuristic: 85% or higher on two consecutive full mocks, with no combined subtopic below 70%. The interface states that this is not a pass prediction.
- **External YouTube dependencies:** Links are now visually and programmatically labeled external, optional, internet-dependent, and outside controlled course content. Replacement or endorsement still requires SME/editorial approval.

### P3: Completed

- Added **Guessed / Unsure / Knew it** confidence ratings after practice responses.
- Confidence now affects adaptive mastery and question prioritization.
- Added **Section X of Y** position on every lesson page.
- Confirmed and expanded global search across lessons, questions, glossary, and standards.
- Verified keyboard-operable paths for the cold-load and synchronization activities inside titled frames.
- Added or enforced `aria-valuetext` for range controls, including embedded activities.

## Important editorial note about length normalization

The automated pass preserves the technical wording of each original choice and appends parallel operating-context qualifiers to remove the exploitable length pattern. The statistical result is validated, but SMEs should review the qualifiers for naturalness during the normal item review. Do not remove them in bulk without replacing them with substantive distractor language, because that would recreate the original cue.
